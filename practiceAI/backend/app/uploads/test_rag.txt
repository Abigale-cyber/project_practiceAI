# Python 列表（List）知识点

## 1. 什么是列表
列表是 Python 中最常用的数据结构之一。它是一个有序的、可变的元素集合，可以包含不同类型的元素。

## 2. 创建列表
创建列表的方式有以下几种：
- 使用方括号 `[]`：`my_list = [1, 2, 3]`
- 使用 `list()` 函数：`my_list = list(range(5))`
- 列表推导式：`squares = [x**2 for x in range(10)]`

## 3. 列表操作
常用的列表操作包括：
- `append(x)`：在末尾添加元素
- `insert(i, x)`：在指定位置插入元素
- `remove(x)`：删除第一个匹配的元素
- `pop(i)`：删除并返回指定位置的元素
- `sort()`：原地排序
- `reverse()`：原地反转

## 4. 列表切片
列表切片语法为 `list[start:stop:step]`。例如：
- `my_list[1:3]` 获取索引 1 到 2 的元素
- `my_list[::-1]` 反转列表
- `my_list[::2]` 获取偶数位置的元素

## 5. 列表与元组的区别
列表是可变的（mutable），而元组是不可变的（immutable）。如果数据不需要修改，推荐使用元组以提高性能。
