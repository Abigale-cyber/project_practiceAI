===================================================================
  「AI 出题官」&「AI 批改官」—— 管理员可配置项方案
===================================================================

一、设计思路
-------------------------------------------------------------------
把 Prompt 中"写死"的行为参数提取出来，变成管理员可在后台调节的
"旋钮"。管理员不需要懂 Prompt，只需要在界面上选择/填写即可。
Prompt 模板保持不变，只是在运行时把这些参数"注入"进去。


二、出题官（Quiz Generator）可配置项
===================================================================

┌──────────────────────────────────────────────────────────────────┐
│  配置项              │  类型      │  默认值    │  说明            │
├──────────────────────────────────────────────────────────────────┤
│  1. 每次出题数量     │  数字滑块  │  5 题      │  范围 3~20       │
│  2. 题型比例         │  下拉选择  │  混合出题  │  可选：          │
│                      │            │            │  - 全部选择题    │
│                      │            │            │  - 全部问答题    │
│                      │            │            │  - 混合(6:4)     │
│  3. 难度级别         │  三档选择  │  适中      │  简单/适中/困难  │
│  4. 考查侧重点       │  多选标签  │  全选      │  可选：          │
│                      │            │            │  - 概念理解      │
│                      │            │            │  - 对比分析      │
│                      │            │            │  - 实际应用      │
│                      │            │            │  - 流程步骤      │
│  5. 自定义出题指令   │  文本框    │  空        │  管理员额外补充  │
│                      │            │            │  例如："侧重考查  │
│                      │            │            │  RAG检索部分"    │
└──────────────────────────────────────────────────────────────────┘

【难度级别】对 Prompt 的影响示例：
  - 简单：题目偏基础概念，选项区分度大，问答题只需列举要点
  - 适中：题目考查理解和比较，选项有一定迷惑性，问答题需要解释
  - 困难：题目涉及综合应用和分析，选项区分度小，问答题需要深入论述

【考查侧重点】示例：
  - 概念理解 → "以下哪个选项正确描述了 RAG 的定义？"
  - 对比分析 → "Naive RAG 和 Advanced RAG 的主要区别是什么？"
  - 实际应用 → "在电商客服场景中，如何设计 RAG 的检索策略？"
  - 流程步骤 → "请按顺序描述 RAG 系统处理一个用户提问的完整流程"


三、批改官（Grading）可配置项
===================================================================

┌──────────────────────────────────────────────────────────────────┐
│  配置项              │  类型      │  默认值    │  说明            │
├──────────────────────────────────────────────────────────────────┤
│  1. 批改严格程度     │  三档选择  │  适中      │  宽松/适中/严格  │
│  2. 反馈风格         │  下拉选择  │  鼓励型    │  可选：          │
│                      │            │            │  - 鼓励型：多表扬│
│                      │            │            │  - 客观型：就事论│
│                      │            │            │    事，不带情感  │
│                      │            │            │  - 严厉型：高标准│
│                      │            │            │    严要求        │
│  3. 及格线           │  数字输入  │  60 分     │  范围 0~100      │
│  4. 答错后是否展示   │  开关      │  开        │  提交后立即展示  │
│     参考答案         │            │            │  正确答案和解析  │
│  5. 自定义批改指令   │  文本框    │  空        │  管理员额外补充  │
│                      │            │            │  例如："重点关注  │
│                      │            │            │  学生是否理解了  │
│                      │            │            │  核心概念"       │
└──────────────────────────────────────────────────────────────────┘

【批改严格程度】对 Prompt 的影响示例：
  - 宽松：学生答到大意即算正确，鼓励为主，只要方向对就给通过
  - 适中：需要覆盖主要得分点，表述大致正确即可
  - 严格：必须准确覆盖所有关键要点，表述需要规范专业

【反馈风格】对输出的影响示例：
  - 鼓励型："你的回答已经抓住了核心要点！👍 如果能再补充 XX 会更完整~"
  - 客观型："回答覆盖了2/3的得分点。缺少对 XX 的说明。"
  - 严厉型："回答不够准确。XX 概念有误，正确的理解应该是……"


四、实现方式（技术层面）
===================================================================

1. 数据库存储：
   settings 表新增字段（或用 JSON 字段存储整个配置）：
   {
     "quiz_count": 5,
     "quiz_type_ratio": "mixed",     // "choice_only" / "essay_only" / "mixed"
     "quiz_difficulty": "medium",     // "easy" / "medium" / "hard"
     "quiz_focus": ["concept", "compare", "apply", "process"],
     "quiz_custom_instruction": "",
     "grading_strictness": "medium",  // "lenient" / "medium" / "strict"
     "grading_style": "encouraging",  // "encouraging" / "objective" / "strict"
     "passing_score": 60,
     "show_answer_after_submit": true,
     "grading_custom_instruction": ""
   }

2. Prompt 动态注入：
   prompts.py 中的模板保持骨架不变，运行时根据配置动态插入参数。
   例如：
     QUIZ_SYSTEM_PROMPT.format(
       difficulty_instruction=难度对应的指令文本,
       focus_instruction=侧重点对应的指令文本,
       custom_instruction=管理员自定义指令,
     )

3. 前端「系统设置」页面：
   在现有的系统设置页面中，分两个 section：
   - 📝 出题设置
   - ✅ 批改设置
   每个 section 里放对应的配置项控件


五、优先级建议
===================================================================

  高优先级（先做）：
    ✅ 出题数量（已有）
    ✅ 题型比例
    ✅ 难度级别
    ✅ 批改严格程度
    ✅ 及格线（已有）

  中优先级（有余力就做）：
    ⬜ 考查侧重点
    ⬜ 反馈风格
    ⬜ 答错后展示参考答案

  低优先级（锦上添花）：
    ⬜ 自定义出题指令
    ⬜ 自定义批改指令
